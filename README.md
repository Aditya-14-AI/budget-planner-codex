# Monthly Expense Tracker Dashboard

A modern, responsive expense tracker built with vanilla HTML/CSS/JavaScript and localStorage.

## Pages
- `index.html` — Dashboard summary and monthly budget input
- `expenses.html` — Add, sort, and delete expenses
- `analytics.html` — Pie, line, and bar chart analytics

## Features
- Budget and expense persistence with `localStorage`
- Add Expense modal with required fields
- Category, date, amount, and payment method tracking
- Sorting transaction columns and deleting entries
- CSV export from any page
- Dark mode toggle with persistence
- Responsive dashboard layout with sidebar navigation

## Run
Open `index.html` directly, or run a local server:

```bash
python -m http.server 4173
```

Then open `http://localhost:4173`.
